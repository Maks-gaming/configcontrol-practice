# Практическое занятие №1

## Задача 1

Отсортированный список имён пользователей из passwd.

```bash
grep -o '^[^:]*' /etc/passwd | sort
```

- `-o` — вывести только совпавшую часть, а не всю строку.
- `^[^:]*` — всё от начала строки до первого `:`, то есть имя пользователя.

## Задача 2

5 протоколов с наибольшими номерами из /etc/protocols.

```bash
grep -v '^#' /etc/protocols | awk '{print $2, $1}' | sort -nr | head -n 5
```

- `grep -v '^#'` — убрать строки-комментарии.
- `awk '{print $2, $1}'` — поменять столбцы местами: номер, название.
- `sort -nr` — по числу, по убыванию.

## Задача 3

Баннер, размер рамки зависит от длины текста.

```bash
#!/bin/bash
text="$1"
line=$(printf '%*s' ${#text} | tr ' ' '-')
echo "+-$line-+"
echo "| $text |"
echo "+-$line-+"
```

- `${#text}` — длина строки.
- `printf '%*s' N | tr ' ' '-'` — строка из N дефисов.

## Задача 4

Все идентификаторы в файле без повторений.

```bash
grep -oE '[A-Za-z_][A-Za-z0-9_]*' hello.c | sort -u | tr '\n' ' '
```

- `[A-Za-z_][A-Za-z0-9_]*` — начинается с буквы или `_`, дальше буквы, цифры, `_`.
- `sort -u` — без повторов.
- `tr '\n' ' '` — вывести в одну строку.

## Задача 6

Проверка комментария в первой строке файлов .c, .js, .py.

```bash
#!/bin/bash
shopt -s nullglob
for f in *.py; do
    if head -n 1 "$f" | grep -q '^#'; then echo "$f: есть"; else echo "$f: нет"; fi
done
for f in *.c *.js; do
    if head -n 1 "$f" | grep -q '^//\|^/\*'; then echo "$f: есть"; else echo "$f: нет"; fi
done
```

- `shopt -s nullglob` — если файлов с таким расширением нет, цикл пропускается.
- `grep -q` — ничего не выводит, только результат для `if`.

## Задача 7

Поиск файлов-дубликатов по содержимому.

```bash
find "$1" -type f -exec md5sum {} + | sort | uniq -w32 -D
```

- `md5sum` — хеш содержимого, у одинаковых файлов он совпадает.
- `uniq -w32 -D` — сравнивать только первые 32 символа (хеш), вывести все повторы.

