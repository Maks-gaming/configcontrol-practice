# Эмулятор оболочки UNIX

Практическая работа по дисциплине «Конфигурационное управление», вариант 16.

Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом
(tkinter). Сейчас реализованы этапы 1 (REPL) и 2 (конфигурация).

## Запуск

```sh
./run.sh [--vfs PATH] [--script PATH]
```

- `--vfs PATH` - путь к XML-файлу VFS (загрузка появится на этапе 3);
- `--script PATH` - стартовый скрипт: команды выполняются построчно,
  на экране видны ввод и вывод, строки с ошибками пропускаются
  с сообщением, строки с `#` считаются комментариями.

При запуске все параметры печатаются в консоль и в окно (`[debug]`).
Скрипты для проверки параметров лежат в `scripts/`.

## Команды

- `ls [-l] [-a] [путь...]` - заглушка, выводит имя и аргументы;
- `cd [путь]` - заглушка, выводит имя и аргумент;
- `exit` - завершить работу.

Переменные окружения `$HOME` и `${HOME}` раскрываются.
